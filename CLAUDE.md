# Detectives (Unity 6, juego narrativo de interrogatorios)

- **Al empezar cada sesión, lee `docs/SKILLS-MAP.md`** (qué skill usar en cada tipo de tarea) y comprueba que las skills cargan como dice `docs/SKILLS-SETUP.md`.
- Las skills del proyecto están en `.claude/skills/`. Se cargan al arrancar el proceso: una sesión que ya estaba abierta no ve las nuevas (`/exit` y `claude --continue`).
- Ramas nuevas desde `main`; `main` solo por fusión aprobada. El repositorio es público: ninguna clave en archivos versionados (`SecretScanTests` y `.githooks/pre-commit`).
